# 一、vue-i18n 核心实现原理

vue-i18n 本质是基于 Vue 的响应式系统封装的国际化插件，核心分为三大模块：

- 语言包管理：加载 / 解析 JSON 语言包，维护不同语言的键值对映射；
- 响应式状态管理：将核心状态（当前语言 locale、语言包 messages）接入 Vue 响应式系统；
- 模板编译 / 运行时替换：通过指令（v-t）或方法（$t）拦截模板渲染，动态替换为对应语言的文本。

先明确两个核心概念的关系

- JSON：是语言包的载体，存储 { 键: 文本 } 的静态数据；
- 响应式：是触发文本更新的动力，当 locale 或 messages 变化时，Vue 响应式系统会自动触发依赖组件的重新渲染。

# 二、JSON 语言包的加载与解析过程

## 1. JSON 语言包的加载方式

- 静态加载：初始化时直接传入 JSON 对象（如 { en: { hello: 'Hello' }, zh: { hello: '你好' } }）；
- 动态加载：通过 i18n.global.setLocaleMessage() 或异步加载（如 import() 加载 JSON 文件后注入）。

## 2.JSON 解析与存储的核心逻辑

```js
// 简化版核心逻辑（模拟 vue-i18n 处理 JSON 的过程）
class I18n {
  constructor(options) {
    // 1. 初始化响应式状态：locale（当前语言）、messages（语言包）
    this._vm = new Vue({
      data: {
        // 响应式的当前语言
        locale: options.locale || "zh",
        // 响应式的语言包（JSON 解析后存储在这里）
        messages: this._normalizeMessages(options.messages || {}),
      },
    });

    // 2. 对外暴露方法（简化版）
    this.t = this._t.bind(this); // $t 方法
    this.setLocaleMessage = this._setLocaleMessage.bind(this);
  }

  // 标准化 JSON 语言包（处理嵌套、空值等）
  _normalizeMessages(messages) {
    const normalized = {};
    for (const locale in messages) {
      // 递归解析嵌套的 JSON 结构，转为扁平/可访问的对象
      normalized[locale] = this._flatten(messages[locale]);
    }
    return normalized;
  }

  // 扁平化嵌套 JSON（如 { a: { b: 'c' } } → { 'a.b': 'c' }）
  _flatten(obj, prefix = "", result = {}) {
    for (const key in obj) {
      const fullKey = prefix ? `${prefix}.${key}` : key;
      if (typeof obj[key] === "object" && obj[key] !== null) {
        this._flatten(obj[key], fullKey, result);
      } else {
        result[fullKey] = obj[key];
      }
    }
    return result;
  }

  // 动态设置语言包（JSON）
  _setLocaleMessage(locale, message) {
    // 解析新的 JSON 并合并到响应式的 messages 中
    this._vm.messages[locale] = {
      ...this._vm.messages[locale],
      ...this._flatten(message),
    };
  }
}
```

- JSON 语言包会被扁平化处理：嵌套的 { a: { b: 'c' } } 转为 { 'a.b': 'c' }，方便通过键路径快速查找；
- 解析后的 JSON 最终存储在 \_vm.messages 中 —— 这是 Vue 响应式对象，后续修改会触发响应式更新。

# 三、响应式更新的触发过程（核心）

vue-i18n 的响应式触发依赖 Vue 的 data/watch/依赖收集 机制，完整触发链路分为 4 步

## 步骤 1：初始化响应式状态

vue-i18n 内部会创建一个 Vue 实例（\_vm），将 locale（当前语言）和 messages（JSON 语言包）存入 data，使其成为响应式数据

```js
// vue-i18n 核心源码简化
this._vm = new Vue({
  data: {
    locale: "zh", // 响应式：当前语言
    messages: {}, // 响应式：解析后的 JSON 语言包
  },
});
```

Vue 会对 locale 和 messages 做响应式处理

## 步骤 2：模板中使用 $t 时收集依赖

当你在模板中写 `{{ $t('hello') }}` 或 `<div v-t="'hello'">` 时，会调用 \_t 方法，这个过程会触发响应式依赖收集：

```js
// 简化版 $t 方法
_t(key) {
  // 1. 访问响应式的 locale → 触发 locale 的 get 方法 → 收集当前组件作为依赖
  const currentLocale = this._vm.locale
  // 2. 访问响应式的 messages → 触发 messages 的 get 方法 → 收集当前组件作为依赖
  const messages = this._vm.messages[currentLocale]
  // 3. 返回对应的文本
  return messages[key] || key
}
```

核心：调用 $t 时，会读取 \_vm.locale 和 \_vm.messages，Vue 会将当前组件的渲染函数加入这两个响应式属性的依赖列表中。

## 步骤 3：触发响应式更新（两种场景）

- 场景 1：切换语言（修改 locale）

```js
// 调用 $i18n.locale = 'en' 时的底层逻辑
Object.defineProperty(this, "locale", {
  get() {
    return this._vm.locale;
  },
  set(newLocale) {
    // 修改响应式的 locale → 触发 set 方法
    this._vm.locale = newLocale;
  },
});
```

修改 locale 时，触发其 set 方法；
Vue 会通知所有依赖 locale 的组件（即所有使用了 $t 的组件）重新渲染。

- 场景 2：更新 JSON 语言包（修改 messages）

```js
// 动态更新语言包（如新增/修改文本）
this.$i18n.setLocaleMessage("zh", { hello: "你好呀" });
```

修改 \_vm.messages 时，触发其 set 方法；
Vue 通知所有依赖 messages 的组件重新渲染，读取新的文本值。

## 步骤 4：组件重新渲染，更新文本

依赖更新后，组件的渲染函数会重新执行：

- 再次调用 $t('hello')；
- 根据最新的 locale 和 messages 读取文本；
- OM 自动更新为新的语言文本。

# 总结

- JSON 处理核心：JSON 语言包会被扁平化解析，最终存储在 Vue 响应式对象 messages 中，为快速查找和响应式更新做准备；
- 响应式触发核心：$t 方法访问 locale/messages 时收集组件依赖，修改 locale（切换语言）或 messages（更新语言包）时触发 set 方法，通知依赖组件重新渲染；
- 本质：vue-i18n 是 Vue 响应式系统的上层封装，JSON 是数据载体，响应式是更新动力，两者通过 \_vm 这个内部 Vue 实例绑定在一起。
